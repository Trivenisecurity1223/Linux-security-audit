# 🔐 Linux System & Network Security Audit

## 📌 Project Overview

This is my first beginner cybersecurity project.

The project performs a basic security audit of a Linux environment using Python.

## 🎯 Objectives

- Collect basic system information
- Identify network information
- Test DNS resolution
- Check common network ports
- Understand basic security auditing

## 🛠️ Tools Used

- Python
- Google Colab
- Linux environment
- GitHub

## 🔍 Project Features

### 1. System Audit

The program collects:

- Current username
- Hostname
- Operating system
- OS version
- Python version

### 2. Network Audit

The program checks:

- Hostname
- IP address
- DNS resolution

### 3. Port Check

The program checks common ports:

- 21 – FTP
- 22 – SSH
- 23 – Telnet
- 25 – SMTP
- 53 – DNS
- 80 – HTTP
- 443 – HTTPS

## 📊 Results

The port connectivity test showed:

- Port 80 – Open
- Port 443 – Open
- Other tested ports – Closed/Filtered

## 🧠 What I Learned

- Linux system information
- IP addresses
- DNS
- Network ports
- TCP connections
- Basic security auditing
- Python networking
